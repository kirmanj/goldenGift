# Golden Gift — 3D category icon prompts

One ready-to-paste prompt per category (50, from the live `categories` collection, 2026-10-22).
All prompts share the same style so the icons look like one set.

## How to use

1. Paste a prompt into your image tool (ChatGPT / DALL·E, Midjourney, Ideogram, Leonardo, Firefly…).
   - **Midjourney:** add ` --ar 1:1 --style raw` at the end (Midjourney can't make transparent backgrounds: ask for a plain white background instead, then remove it).
   - **Stable Diffusion / Leonardo:** use the negative prompt below.
2. Export **1024 × 1024 PNG with a transparent background**. If your tool can't do transparency, generate on plain white and remove the background (e.g. remove.bg, Photoshop, Canva).
   The icon sits on a soft grey tile — light `#F3F2EC`, dark `#242427` — so it must not have its own background square.
3. Upload: dashboard → **Categories** → edit the category → **Icon** → Upload. It is saved as `categories/{id}.png`.
4. Generate 2–4 variations of the first icon, pick the look you like, then reuse the same tool, settings and (if supported) style reference / seed for the rest so the set stays consistent.

**Negative prompt** (tools that support it): `text, letters, words, numbers, logo, watermark, signature, background, frame, border, photo, realistic photo, flat 2D, outline icon, blurry, low quality, cropped, multiple separate icons`

## Shared style (already included in every prompt)

> soft 3D clay-like render with smooth, slightly glossy surfaces, rounded chunky friendly shapes, premium gift-shop icon, main palette warm gold (#C9A227) and cream white with <accent> as the accent colour, three-quarter front view, single centred object group with generous empty padding around it, soft diffuse studio lighting, a subtle soft contact shadow underneath, fully transparent background, no text, no letters, no numbers, no logos, no watermark, consistent style for a matching set of 50 category icons, square 1:1, 1024x1024
